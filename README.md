# わたしのキャラずかん

紙に描いたキャラクターの絵をスマホで撮影して取り込み、名前や性格などの設定を書き込んで「図鑑」にまとめるアプリです。

- HTML / CSS / JavaScript だけで動きます(ビルド不要・サーバー不要)
- データ(設定と画像)は**その端末のブラウザの中(IndexedDB)だけ**に保存されます。外部との通信は一切しません
- PWA 対応:ホーム画面に追加でき、オフラインでも動きます

## 使い方

| やりたいこと | 操作 |
| --- | --- |
| キャラを登録する | 一覧の「＋」→「📷 しゃしんをとる/えらぶ」→ 丸い枠で切り抜く →「えの かんじ」を選ぶ → 設定を書いて「💾 ほぞんする」 |
| 切り抜き・絵の感じをやり直す | 登録画面の「✂️ きりぬき・えのかんじを なおす」(元の写真も保存しているので、撮り直しは不要) |
| 詳しく見る | 一覧のカードをタップ |
| 直す・消す | 詳しく見る画面の「✏️ なおす」「🗑 けす」 |
| バックアップ | 右上の ⚙︎ →「📤 バックアップをかきだす」/「📥 バックアップをよみこむ」 |
| キャラを動かして遊ぶ | 詳しく見る画面か一覧の「🎬 うごかして あそぶ」→ キャラをタップして「うごき」を選ぶ。指でドラッグすると場所が変わる |

- 入力中の内容は自動で下書き保存されます。途中でアプリを閉じても、次に開いたときに続きから書けます
- 「ねんれい」は数字だけ入力できます。「なまえ」以外は空のままでも保存できます
- 切り抜き画面では、1本指で位置を動かし、2本指のピンチまたは下のスライダーで大きさを変えます(PC ではマウスホイールでも変更できます)
- 「えの かんじ」では、「📷 そのまま」と「🎨 まんがふう」(つよさ:よわい/ふつう/つよい)を見くらべて選べます。最初は「まんがふう・ふつう」が選ばれています

### まんがふうの仕組み

変換はすべて端末の中(Web Worker)で行い、画像を外に送ることはありません。

1. 紙の影や色のムラを補正して、背景を白くする(スキャナーで取り込んだような状態にする)
2. 色を少し鮮やかにする
3. 輪郭を残したまま色をなめらかにする(Kuwahara フィルター)
4. 色の数を減らしてベタ塗りにする(k-means。よわい 16色/ふつう 10色/つよい 8色)
5. 黒い輪郭線を足す(XDoG)

保存されるのは変換後の絵(図鑑に表示されるもの)と元の写真の両方なので、あとから「そのまま」に戻すこともできます。

## ⚠️ データについての大事な注意

- **データはその端末の中にしかありません。** 機種変更や、Safari の「履歴とWebサイトデータを消去」をするとデータが消えます。ときどきバックアップを書き出して、iCloud Drive などに保存してください
- **iPhone では「Safari で開いたもの」と「ホーム画面に追加したもの」でデータが別々です。** 使い始める前にホーム画面に追加して、いつもホーム画面のアイコンから開くようにしてください(Safari で登録したキャラを移したいときは、バックアップの書き出し → 読み込みで移せます)
- ホーム画面に追加したアプリは、iOS がデータを自動で消す対象から外れるので、データが消えにくくなります
- バックアップを読み込むと、**今あるキャラはすべてファイルの内容に入れ替わります**(読み込む前に確認が出ます)

## ファイル構成

```
index.html          画面(1ページの中で表示を切り替え)
style.css           見た目
js/app.js           画面の切り替え・入力・下書き・バックアップ操作
js/db.js            IndexedDB(キャラ・下書きの保存)
js/image.js         画像の読み込み・縮小(長辺 1024px)・JPEG 化
js/cropper.js       丸い切り抜き(Canvas で自作)
js/styler.js        「えの かんじ」を選ぶ画面
js/manga-worker.js  まんがふうフィルター(Web Worker)
js/backup.js        バックアップ JSON の作成と読み込み
js/anime.js         「うごかして あそぶ」画面(動き・ふきだし・なかまを呼ぶ)
js/cutout.js        キャラの絵のまわりの白を透明にして、シールのような白いふちをつける
js/scenery.js       ぶたいの背景(画像を使わず Canvas で描く)
sw.js               Service Worker(オフライン用キャッシュ)
manifest.json       PWA の設定
icons/              アイコン(tools/make_icons.py で生成)
tools/              開発用スクリプト(アイコン生成・構文チェック・フィルターのお試し)
compose.yaml, docker/dev.Dockerfile   開発用コンテナ
```

## ローカルで確認する

Docker Desktop が必要です(Windows に Python や Node.js を入れる必要はありません)。

```sh
docker compose up dev        # http://localhost:8000 で起動(止めるときは Ctrl+C)
```

PC のブラウザで http://localhost:8000 を開きます。Chrome の開発者ツールでスマホ表示(Ctrl+Shift+M)にすると、スマホの縦画面に近い見た目で確認できます。

そのほかのコマンド:

```sh
docker compose run --rm dev sh tools/check.sh             # JS と manifest の構文チェック
docker compose run --rm dev python tools/make_icons.py    # アイコンを作り直す
docker compose run --rm dev python tools/try_manga.py photo.jpg   # まんがふうフィルターを写真で試す
```

`try_manga.py` は、このフォルダに置いた写真に「よわい/ふつう/つよい」のフィルターをかけ、元の写真と並べた `photo-manga.png` を作ります。フィルターの調子を PC で確かめたいときに使います(試した写真は commit しないように注意してください)。

> **iPhone で実機確認するときの注意**
> Service Worker(オフライン・ホーム画面アプリ)は **https か localhost でしか動きません**。PC の IP アドレス(http://192.168.x.x:8000)を iPhone で開くと画面の確認はできますが、オフラインやホーム画面アプリの確認はできません。実機での最終確認は、GitHub Pages(https)に公開してから行ってください。

## アプリを更新するとき

アプリのファイルを変更したら、**`sw.js` の先頭にある `VERSION` の数字を 1 つ増やしてください。**

```js
const VERSION = 2;   // ← 1 → 2 のように増やす
```

こうすると、アプリを開いたときに新しい版が見つかり、画面に「あたらしい バージョンが あるよ」と出ます。「あたらしくする」を押すと切り替わります(入力途中の下書きは保存されてから切り替わります)。
ファイルを追加したときは、`sw.js` の `FILES` にも追加してください。

ローカルで開発中に変更がすぐ反映されないときは、Chrome の開発者ツール →「Application」→「Service workers」→「Update on reload」にチェックを入れてください。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作成します(例:`chara-zukan`)。公開範囲は Public にします(無料プランで Pages を使う場合)
2. このフォルダを push します
   ```sh
   git remote add origin https://github.com/<ユーザー名>/chara-zukan.git
   git push -u origin main
   ```
3. GitHub のリポジトリ画面で **Settings → Pages** を開きます
4. 「Build and deployment」の **Source** を「Deploy from a branch」にします
5. **Branch** を `main`、フォルダを `/ (root)` にして **Save** を押します
6. 1〜2 分待つと、`https://<ユーザー名>.github.io/chara-zukan/` で公開されます(Pages の画面に URL が表示されます)

- すべて相対パスで書いてあるので、`/chara-zukan/` のようなサブパスでもそのまま動きます
- 公開されるのはアプリのプログラムだけです。**キャラのデータや写真は各端末の中だけにあり、GitHub には一切アップロードされません**
- 更新するときは、`sw.js` の `VERSION` を増やしてから push してください

## iPhone のホーム画面に追加する

1. iPhone の **Safari** で公開した URL を開きます
2. 画面下(または上)の **共有ボタン**(四角から上向き矢印が出ているアイコン)をタップします
3. メニューを下にスクロールして **「ホーム画面に追加」** をタップします
4. 名前が「キャラずかん」になっていることを確認して、右上の **「追加」** をタップします
5. ホーム画面にできたアイコンから開くと、アプリのように全画面で使えます。一度開けば、機内モードでも使えます

> iOS のバージョンによっては、「ホーム画面に追加」のあとに「Webアプリとして開く」のスイッチが出ます。オンのままにしてください。

## バックアップを iPhone に保存する

1. ⚙︎ →「📤 バックアップをかきだす」→「💾 ほぞんする」をタップします
2. 共有メニューが開くので **「"ファイル"に保存」** を選び、iCloud Drive などに保存します
3. 読み込むときは「📥 バックアップをよみこむ」→ 保存したファイル(`chara-zukan-年月日.json`)を選びます

## 動作確認チェックリスト

段階ごとに、次の項目を確認できます。

**1. 起動と空の状態**
- [ ] 初めて開くと「さいしょのキャラをとうろくしよう!」が出る
- [ ] スマホ幅・PC 幅の両方で表示が崩れない

**2. 登録・下書き**
- [ ] なまえを空にして「ほぞんする」→「なまえを いれてね」と出る
- [ ] ねんれいに文字や記号を入れようとしても数字だけ残る(全角数字は半角になる)
- [ ] 入力途中で一覧に戻る/タブを閉じる → もう一度「＋」で、続きが残っている
- [ ] 「やめる」で確認が出て、「けして もどる」で下書きが消える
- [ ] 保存すると詳しく見る画面に移り、一覧にカードが新しい順で並ぶ

**3. 写真・切り抜き**
- [ ] iPhone で「しゃしんをとる/えらぶ」→ カメラ撮影と写真ライブラリの両方が選べる
- [ ] **iPhone で縦向き・横向きに撮った写真が、どちらも正しい向きで表示される**(EXIF の確認)
- [ ] ドラッグで移動、ピンチ/スライダーで拡大縮小できる
- [ ] 切り抜きのあと「えの かんじ」画面が出て、「そのまま」「まんがふう」(よわい/ふつう/つよい)を切り替えて見くらべられる
- [ ] まんがふうにすると、紙の背景が白くなり、色がベタ塗り+黒い輪郭線になる
- [ ] 「◀ きりなおす」で切り抜きに戻れ、選んだ絵の感じは覚えている
- [ ] 「きりぬき・えのかんじを なおす」で、前回の位置と絵の感じから調整できる

**4. 詳しく見る・直す・消す**
- [ ] カードをタップすると全項目が見られる(空の項目は「まだ かいてないよ」)
- [ ] 「なおす」で内容が入った状態のフォームが開き、保存すると反映される
- [ ] 「けす」で「ほんとうに けす?」と確認が出る

**5. バックアップ**
- [ ] 書き出したファイルを読み込むと、確認のあと全キャラが元に戻る
- [ ] 関係ないファイルを選ぶと「よみこめなかったよ」と出て、データは変わらない

**6. うごかして あそぶ**
- [ ] 詳しく見る画面の「🎬 うごかして あそぶ」で、そのキャラがぶたいに出てくる(くちぐせがあれば、ふきだしに入っている)
- [ ] まんがふうの絵は、まわりの白が消えて、白いふちのシールのように見える
- [ ] キャラをタップすると点線のまるが出て、うごき(9種類)・おおきさ・ふきだし・むきを変えられる
- [ ] 指でドラッグすると場所が変わる。「てくてく」のキャラも、指をはなすと続きから歩く
- [ ] 「＋ なかまを よぶ」で 4 人まで呼べる。「👋 ばいばい」でぶたいから外れる
- [ ] はいけい 6 種類を切り替えられる。⏸ / ▶ で止める・動かすを切り替えられる
- [ ] 別の画面に行って戻っても、ぶたいの状態が残っている

**7. PWA**
- [ ] ホーム画面に追加でき、アイコンと名前が正しい
- [ ] 機内モードでもホーム画面のアイコンから起動・登録ができる
- [ ] `VERSION` を増やして公開し直すと「あたらしい バージョンが あるよ」が出る
